# REST and WebSocket contracts

Source of truth: `packages/kimo-client/src/schema.ts`. All responses are parsed with Zod at the client boundary. All server requests are validated before mutation. See exported schemas for every property and variant.

REST: POST /v1/uploads; POST /v1/uploads/:assetId/complete; POST /v1/sessions; GET /v1/sessions/:id; POST /v1/sessions/:id/messages (202); POST /v1/sessions/:id/ops (409 on stale baseVersion); POST /v1/sessions/:id/approve; GET /v1/renders/:id; GET /v1/videos/:id. Base defaults http://localhost:8787; configurable NEXT_PUBLIC_KIMO_API.

Multipart Phase 3 extension: sizes >100 MiB return 16 MiB presigned parts, numbered from1. PUT returns exposed ETag. Complete POST body {parts:[{partNumber,etag}]} validates ordered matching parts before joining. Ordinary PUT body is bytes, never JSON. Asset IDs are available before bytes complete. Signed mock URLs live 15 minutes. Session snapshot additionally returns wsUrl and optional videoId for restore.

Legacy nested values remain valid: TextStyleId title|caption|lower_third; Effect {id,kind,params:Record<string,string|number|boolean>}; Keyframe {property,time,value,easing?:linear|ease_out|ease_in_out}; Transition {kind:cut|crossfade|dip,duration}. Phase 6 additions and normalization are specified below. Marker remains {id,time,label}; crop remains nonnegative {l,t,r,b}, without tightening legacy crop units. All Op variants have typed payloads, no any.

Version: every batch increments once. Gap causes GET and replacement. Optimistic edits send previous baseVersion; on409 refetch, reapply once and resubmit; a second conflict refetches and surfaces failure. Pause/resume/interrupt/ping are native WS client packets; malformed packets never mutate project state.

## Optional session action history (Phase 5 restore)

`SessionSnapshot.actionIds?: string[]` contains unique server-recorded `agent.action.start.id` values for that session. IDs are nonempty strings using the existing ID schema. This is recorded action history, not a count or IDs inferred from `project.version`, `project.ops.actionId`, review status, or project contents. Servers supplying the field must record each unique start ID when emitting the event, including when no client is connected; the mock stores it in its in-memory session snapshot and includes it in GET /v1/sessions/:id. This does not add disk persistence across mock restarts. Client-originated op batches do not add IDs.

The field is optional for backward compatibility: older snapshots still validate without it, and omission is not converted into fabricated history. Studio resets session state, hydrates `snapshot.actionIds ?? []`, and deduplicates incoming live starts against those IDs. A nonempty supplied history preserves action count and finish eligibility on reload; an omitted or empty history leaves finish disabled until an actual start arrives. No event replay or new endpoint is required.

## Phase 6 additive contracts (PROPOSED, not backend agreement)

All additions are optional unless an explicitly new discriminant needs its payload. Legacy snapshots, events, action IDs, op names and op revision semantics are unchanged. Parsing does not insert defaults. New enum members are **not** forward-compatible with old clients; coordinate producer rollout/capability negotiation before emitting them. `project.version` remains an operation revision, not a schema version. The shared nested schemas apply equally in project snapshots, clip/track patches, effect/keyframe ops and WS packets.

- **Transitions:** legacy `duration` seconds remains valid; `durationFrames` is an optional nonnegative safe integer. At least one is required; if both exist they must agree at the existing project 30 fps within 1e-6 seconds. Kinds: cut, crossfade, dip, slide, zoom_in, whip. Optional direction left/right/up/down defaults to left only during scene normalization. Zero duration is a no-op; frames take precedence in resolver math. Same-track butt-cut neighbors resolve as explicit pairs around the boundary `[b-D/2,b+D/2)`, where D is bounded by both adjacent durations. Incoming transitionIn wins/coalesces outgoing transitionOut, conflicts flagged. Paired crossfade/zoom use one weighted premultiplied RGBA composite, dip additionally weights opaque black; never draw both weighted alphas separately. Available source-in and metadata-proven source-out handles are used. Missing handles freeze actual first/last boundary content and annotate approximation, never seek negative or exclusive-end source timestamps. Pure options.sourceFps supplies an explicit freeze-frame quantum, project fps is provisional fallback. Unpaired/gap transitions retain an explicitly approximate local fallback. This is implemented preview semantics, not a backend agreement claim; see FIDELITY.
- **Keys:** optional easing additionally accepts hold/bezier. Missing easing means linear. `bezier:[x1,y1,x2,y2]` is required exactly when easing=bezier; all handles/values finite, x handles in [0,1], y handles may overshoot. Key time is timeline seconds on the animation clock, not source seconds. Departing key controls interpolation. Duplicate property/time ops replace the prior key; resolver sorts copies and holds endpoints. Scalar paths recognized by the core: x/y/scale/rotation/opacity (also transform-prefixed), volume, and `effects.<effectId>.<scalarParam>`. Other paths are retained with approximation warnings.
- **Splits:** optional clip `animationOffsetSec` defaults to zero; right split receives old offset+(splitAt-oldStart). Keys and words remain copied without mutation. Source in remains `oldIn+(splitAt-oldStart)*speed`; duration/start formulas are unchanged. Repeat splits accumulate offsets. This explicitly fixes the formerly unrepresented animation clock. In/out trim behavior is deliberately unchanged, including legacy animation rebasing behavior; no hidden migration of saved timing. Pure scene normalization groups contiguous copied split fragments sharing kind/asset/speed, continuous source/animation clocks and equivalent transition fields. Transition boundaries and duration-based envelopes use that logical span, while actual fragment IDs/data remain distinct. No inherited transition is restarted at an internal split. A changed transition, discontinuity or speed breaks grouping. This is explicit proposed preview policy, not a new wire field or a backend agreement claim.
- **Text:** exact IDs caption-clean, caption-pop, caption-box, title-serif, title-bold, lower-third, label-mono, quote. Legacy aliases normalize only at compositor boundary: title -> title-serif, caption -> caption-clean, lower_third -> lower-third. Optional `secondaryContent` defaults empty. Word t/d are animation-clock seconds, active on [t,t+d); all overlapping active words are preserved, not arbitrarily reduced to one. No content is inferred from words or secondary strings.
- **Shapes:** optional `shape` payload is consumed only for kind=shape. `{kind:'rect',width,height,fill:[r,g,b,a],radius?,stroke?,strokeWidth?}` uses positive project-pixel width/height, nonnegative radius/strokeWidth. `{kind:'line',x1,y1,x2,y2,stroke:[r,g,b,a],strokeWidth}` uses finite project-pixel endpoints and positive strokeWidth. Colors are finite normalized RGBA [0,1]. Radius/width absence means 0. Rect is centered on the clip transform origin; line endpoints are local to it. Missing geometry is an approximation reason, never an invented bar.
- **Masks:** optional asset `mask` is a discriminated metadata descriptor; asset kinds remain unchanged. Every descriptor has positive safe integer width/height, coordinateSpace=source_uv, optional nonnegative timeOrigin (default 0), and an explicit channel alpha/luma/red. encoding=video requires positive fps; luma_image is static and needs no fps. encoding=rle requires fps, channel=luma, version=1 and payloadUrl. Version 1 decoded frames follow exported `maskRleFrameSchema`: frameIndex nonnegative integer, dimensions, counts of alternating zero/one row-major runs, starting with zero; runs must cover exactly width*height safe-integer pixels. Payload decoding/network loading belongs to media ownership. Missing RLE frames must be reported unavailable; never silently hold or fabricate masks. Temporal frame index=floor((sourceTime-timeOrigin)*fps); negative index means unavailable. Optional clip mask.mode selection/cutout defaults selection in the preview only. Existing invert and feather survive; legacy feather units are unresolved and nonzero values are flagged. Invert applies after feather. Unlabelled masks do not imply a person.
- **LUT:** optional asset `lut:{size:64,layout:'tiles_8x8',colorSpace:'srgb'}` declares a 512x512 atlas, r/g in each tile, blue slice at (b%8,floor(b/8)), top-left image row origin and half-texel sampling centers. `params.lutAssetId` references it. Dimensions alone are not LUT evidence. This is a proposed contract, not validation of backend atlas ordering.
- **Effects:** optional scope all/inside_mask/outside_mask defaults all. Existing ordered finite scalar/string/boolean params remain; no unknown effect is dropped. Selection scopes blend with mask/inverse mask, independent of whole-layer cutout. Unknown/heavy kinds are annotated for approximate rendering. Legacy generic ducking params are not silently migrated to the role-based policy.
- **Audio:** optional clip.audioRole voice/music/other defaults other. No classification from names or track kinds. Optional track.solo defaults false. Any solo track gates non-solo audio; muted wins. Hidden is visual-only; locked is editing-only. Volume and volume keyframes are nonnegative linear gains in preview, default 1; keyframes override rather than multiply the base. Voice timeline intervals that pass track gates trigger proposed -12 dB music ducking with continuous 300ms linear gain attack/release, including overlapping/interrupted voices. This policy does not promise equivalent legacy generic ducking effects. Scene audio.gain already includes master/gates/duck; do not apply those twice if consuming resolved audio.
- **Action targeting:** optional target.time is nonnegative timeline seconds. Optional target.previewPolygon uses normalized source_uv vertices, optional target.coordinateSpace explicitly marks that basis, optional subjectLabel is untrusted display text, not a classifier assertion. Existing target.region stays project-pixel x/y/w/h. Optional sam.mask.actionId correlates the action start ID; optional subjectLabel/coordinateSpace preserve explicit event metadata. Legacy sam.mask previewPolygon remains required and keeps existing numeric validation; without coordinateSpace its basis is unverified. Never infer correlation solely from event order.

Missing Phase 6 fields are normalized explicitly in the pure compositor, not rewritten into saved projects. Asset metadata is injected into `build(project,t,{assets})`; the builder never looks up globals, loads resources or accesses wall time. These contracts do not certify font readiness, decoded frames, backend fidelity or browser performance.
