# REST and WebSocket contracts

Source of truth: `packages/kimo-client/src/schema.ts`. All responses are parsed with Zod at the client boundary. All server requests are validated before mutation. See exported schemas for every property and variant.

REST: POST /v1/uploads; POST /v1/uploads/:assetId/complete; POST /v1/sessions; GET /v1/sessions/:id; POST /v1/sessions/:id/messages (202); POST /v1/sessions/:id/ops (409 on stale baseVersion); POST /v1/sessions/:id/approve; GET /v1/renders/:id; GET /v1/videos/:id. Base defaults http://localhost:8787; configurable NEXT_PUBLIC_KIMO_API.

Multipart Phase 3 extension: sizes >100 MiB return 16 MiB presigned parts, numbered from1. PUT returns exposed ETag. Complete POST body {parts:[{partNumber,etag}]} validates ordered matching parts before joining. Ordinary PUT body is bytes, never JSON. Asset IDs are available before bytes complete. Signed mock URLs live 15 minutes. Session snapshot additionally returns wsUrl and optional videoId for restore.

Legacy nested values remain valid: TextStyleId title|caption|lower_third; Effect {id,kind,params:Record<string,string|number|boolean>}; Keyframe {property,time,value,easing?:linear|ease_out|ease_in_out}; Transition {kind:cut|crossfade|dip,duration}. Phase 6 additions and normalization are specified below. Marker remains {id,time,label}; crop remains nonnegative {l,t,r,b}, without tightening legacy crop units. All Op variants have typed payloads, no any.

Version: every batch increments once. Gap causes GET and replacement. Optimistic edits send previous baseVersion; on409 refetch, reapply once and resubmit; a second conflict refetches and surfaces failure. Pause/resume/interrupt/ping are native WS client packets; malformed packets never mutate project state.

## Optional session action history (Phase 5 restore)

`SessionSnapshot.actionIds?: string[]` contains unique server-recorded `agent.action.start.id` values for that session. IDs are nonempty strings using the existing ID schema. This is recorded action history, not a count or IDs inferred from `project.version`, `project.ops.actionId`, review status, or project contents. Servers supplying the field must record each unique start ID when emitting the event, including when no client is connected; the mock stores it in its in-memory session snapshot and includes it in GET /v1/sessions/:id. This does not add disk persistence across mock restarts. Client-originated op batches do not add IDs.

The field is optional for backward compatibility: older snapshots still validate without it, and omission is not converted into fabricated history. Studio resets session state, hydrates `snapshot.actionIds ?? []`, and deduplicates incoming live starts against those IDs. A nonempty supplied history preserves action count and finish eligibility on reload; an omitted or empty history leaves finish disabled until an actual start arrives. No event replay or new endpoint is required.

## Phase 6 additive contracts (PROPOSED, not backend agreement)

All additions are optional unless an explicitly new discriminant needs its payload. Legacy snapshots, events, action IDs, op names and op revision semantics are unchanged. Parsing does not insert defaults. New enum members are **not** forward-compatible with old clients; coordinate producer rollout/capability negotiation before emitting them. `project.version` remains an operation revision, not a schema version. The shared nested schemas apply equally in project snapshots, clip/track patches, effect/keyframe ops and WS packets.

- **Transitions:** legacy `duration` seconds remains valid; `durationFrames` is an optional nonnegative safe integer. At least one is required; if both exist they must agree at the existing project 30 fps within 1e-6 seconds. Kinds: cut, crossfade, dip, slide, zoom_in, whip. Optional direction left/right/up/down defaults to left only during scene normalization. Zero duration is a no-op; frames take precedence in resolver math. Same-track butt-cut neighbors resolve as explicit pairs around the boundary `[b-D/2,b+D/2)`, where D is bounded by both adjacent durations. Incoming transitionIn wins/coalesces outgoing transitionOut, conflicts flagged. Paired crossfade/zoom use one weighted premultiplied RGBA composite, dip additionally weights opaque black; never draw both weighted alphas separately. Available source-in and metadata-proven source-out handles are used. Missing handles freeze actual first/last boundary content and annotate approximation, never seek negative or exclusive-end source timestamps. Pure options.sourceFps supplies an explicit freeze-frame quantum, project fps is provisional fallback. Unpaired/gap transitions retain an explicitly approximate local fallback. This is implemented preview semantics, not a backend agreement claim; see FIDELITY.
- **Keys:** optional easing additionally accepts hold/bezier. Missing easing means linear. `bezier:[x1,y1,x2,y2]` is required exactly when easing=bezier; all handles/values finite, x handles in [0,1], y handles may overshoot. Key time is timeline seconds on the animation clock, not source seconds. Departing key controls interpolation. Duplicate property/time ops replace the prior key; resolver sorts copies and holds endpoints. Scalar paths recognized by the core: x/y/scale/rotation/opacity (also transform-prefixed), volume, and `effects.<effectId>.<scalarParam>`. Other paths are retained with approximation warnings.
- **Splits:** optional clip `animationOffsetSec` defaults to zero; right split receives old offset+(splitAt-oldStart). Keys and words remain copied without mutation. Source in remains `oldIn+(splitAt-oldStart)*speed`; duration/start formulas are unchanged. Repeat splits accumulate offsets. This explicitly fixes the formerly unrepresented animation clock. In/out trim behavior is deliberately unchanged, including legacy animation rebasing behavior; no hidden migration of saved timing. Pure scene normalization groups contiguous copied split fragments sharing kind/asset/speed, continuous source/animation clocks and equivalent transition fields. Transition boundaries and duration-based envelopes use that logical span, while actual fragment IDs/data remain distinct. No inherited transition is restarted at an internal split. A changed transition, discontinuity or speed breaks grouping. This is explicit proposed preview policy, not a new wire field or a backend agreement claim.
- **Text:** exact IDs caption-clean, caption-pop, caption-box, title-serif, title-bold, lower-third, label-mono, quote. Legacy aliases normalize only at compositor boundary: title -> title-serif, caption -> caption-clean, lower_third -> lower-third. Optional `secondaryContent` defaults empty. Word t/d are animation-clock seconds, active on [t,t+d); all overlapping active words are preserved, not arbitrarily reduced to one. No content is inferred from words or secondary strings.
- **Shapes:** optional `shape` payload is consumed only for kind=shape. `{kind:'rect',width,height,fill:[r,g,b,a],radius?,stroke?,strokeWidth?}` uses positive project-pixel width/height, nonnegative radius/strokeWidth. `{kind:'line',x1,y1,x2,y2,stroke:[r,g,b,a],strokeWidth}` uses finite project-pixel endpoints and positive strokeWidth. Colors are finite normalized RGBA [0,1]. Radius/width absence means 0. Rect is centered on the clip transform origin; line endpoints are local to it. Missing geometry is an approximation reason, never an invented bar.
- **Masks:** optional asset `mask` is a discriminated metadata descriptor; asset kinds remain unchanged. Every descriptor has positive safe integer width/height, coordinateSpace=source_uv, optional nonnegative timeOrigin (default 0), and an explicit channel alpha/luma/red. encoding=video requires positive fps; luma_image is static and needs no fps. encoding=rle requires fps, channel=luma, version=1 and payloadUrl. Version 1 decoded frames follow exported `maskRleFrameSchema`: frameIndex nonnegative integer, dimensions, counts of alternating zero/one row-major runs, starting with zero; runs must cover exactly width*height safe-integer pixels. Payload decoding/network loading belongs to media ownership. Missing RLE frames must be reported unavailable; never silently hold or fabricate masks. Temporal frame index=floor((sourceTime-timeOrigin)*fps); negative index means unavailable. Optional clip mask.mode selection/cutout defaults selection in the preview only. Existing invert and feather survive; legacy feather units are unresolved and nonzero values are flagged. Invert applies after feather. Unlabelled masks do not imply a person.
- **LUT:** optional asset `lut:{size:64,layout:'tiles_8x8',colorSpace:'srgb'}` declares a 512x512 atlas, r/g in each tile, blue slice at (b%8,floor(b/8)), top-left image row origin and half-texel sampling centers. `params.lutAssetId` references it. Dimensions alone are not LUT evidence. This is a proposed contract, not validation of backend atlas ordering.
- **Effects:** optional scope all/inside_mask/outside_mask defaults all. Existing ordered finite scalar/string/boolean params remain; no unknown effect is dropped. Selection scopes blend with mask/inverse mask, independent of whole-layer cutout. Unknown/heavy kinds are annotated for approximate rendering. Legacy generic ducking params are not silently migrated to the role-based policy.
- **Audio:** optional clip.audioRole voice/music/other defaults other. No classification from names or track kinds. Optional track.solo defaults false. Any solo track gates non-solo audio; muted wins. Hidden is visual-only; locked is editing-only. Volume and volume keyframes are nonnegative linear gains in preview, default 1; keyframes override rather than multiply the base. Voice timeline intervals that pass track gates trigger proposed -12 dB music ducking with continuous 300ms linear gain attack/release, including overlapping/interrupted voices. This policy does not promise equivalent legacy generic ducking effects. Scene audio.gain already includes master/gates/duck; do not apply those twice if consuming resolved audio.
- **Action targeting:** optional target.time is nonnegative timeline seconds. Optional target.previewPolygon uses normalized source_uv vertices, optional target.coordinateSpace explicitly marks that basis, optional subjectLabel is untrusted display text, not a classifier assertion. Existing target.region stays project-pixel x/y/w/h. Optional sam.mask.actionId correlates the action start ID; optional subjectLabel/coordinateSpace preserve explicit event metadata. Legacy sam.mask previewPolygon remains required and keeps existing numeric validation; without coordinateSpace its basis is unverified. Never infer correlation solely from event order.

Missing Phase 6 fields are normalized explicitly in the pure compositor, not rewritten into saved projects. Asset metadata is injected into `build(project,t,{assets})`; the builder never looks up globals, loads resources or accesses wall time. These contracts do not certify font readiness, decoded frames, backend fidelity or browser performance.

## Phase 7 editing foundation (PROPOSED; production agreement unverified)

These are additive frontend/client contracts, not engine changes or a claim that the production server, compositor or audio engine consumes the new fields. The parent owns Shell integration, the single WebSocket, renderer/audio hooks, server lock acceptance, global gates and publication. Source tests do not establish GPU availability, visual fidelity, hardware performance, reframing, pitch preservation or server acceptance.

### Typed inspector payloads

Optional `clip.text` fields: `fontSize` is positive finite content pixels; `alignment` is `left|center|right`; `color` is normalized finite `[r,g,b,a]`; `animation` is exactly `none|fade|rise|type on|pop words`; `position` is `bottom|middle|top`. Existing style IDs, secondaryContent, and timed words remain compatible. `text.update` accepts optional `words` and `secondaryContent` with no inserted defaults. Legacy content-only operations retain previous word timings; new text editors must use `textUpdate` to send content and recomputed words in ONE operation. Same token count retains original t/d by index; changed count distributes inside `[animationOffsetSec,animationOffsetSec+duration]`. Empty/whitespace content sends an empty words array. Composition, native caret/undo, 150ms local debounce and 800ms idle/blur lifecycle remain the text UI owner's responsibility.

Optional video/audio fields are `fadeInSec`, `fadeOutSec` (finite nonnegative seconds), `keepPitch`, `duckUnderVoice`, and `linkGroupId` (nonempty string). Linear volume remains linear; inspector bounds are -60 to +12 dB. Optional `effect.enabled` retains ordered effects when toggled. Known numeric filter parameters validate against exported `effectParameterBounds`, copied from existing pure renderer bounds; unknown effect kinds/parameters retain the legacy finite scalar/string/boolean representation. No SAM feather unit is asserted: it remains nonnegative with existing unresolved-unit fidelity warning.

Optional project `background` is normalized RGBA, `notes` is text. `project.update` permits only background/notes and paired width/height of 1920x1080,1080x1920,1080x1080. It rejects lone dimensions, 1920x1920, unknown patch keys and fps edits. The operation changes data only; it does NOT claim that kimo reframed every clip or received notes as conversational context. Parent must arrange actual reframing/context effects before reporting those outcomes.

The sole new track operation is `track.remove {id}`, permitted by editing validation only for empty unlocked tracks. Reducer rejects a nonempty removal to prevent dangling references. It is necessary for undo of a detach batch that creates an audio track. No track.reorder or cascade-delete protocol was invented. History cannot reconstruct arbitrary removed-track insertion order; unavailable inverses are surfaced rather than fabricated.

### Editing session API and projection

`createEditingSession(EditContext)` is a structural, isolated controller with no UI/Studio/GPU/socket imports. It supplies beginEdit/previewEdit/commitEdit/cancelEdit, editGroup, undoUser/redoUser, revertAgentGroup(actualActionId), receiveAuthoritative, replaceSnapshot, suggestion resolution, flush, subscriptions and dispose. `stores/editing` is the Zustand adapter. `useProject.replace/receive/edit` signatures remain valid; parent may attach a fully injected context. The displayed `useProject.project` remains the project-identity subscription seam for observeCompositor.

Acknowledged snapshot/version, ordered pending groups and active draft are separate. Display projection keeps the acknowledged version, including during repeated draft frames. Preview replaces the draft against the begin baseline, does no HTTP, and advances no server revision. Commit is one logical batch and repeated commit calls reuse its promise. Callers coalesce pointer previews per rAF and own debounce/IME timers. `getState` identity is stable between notifications. Shell must compare incoming events to `acknowledgedVersion`, NEVER a pending/draft display revision, and feed the one existing socket to receiveAuthoritative with all available metadata.

Authority advances immediately during soft locks. Locked clip display uses its begin baseline plus current draft; other clips advance normally. On release, the current authoritative state plus user ops becomes visible. A server clip.remove cancels affected drafts immediately, calls selection cleanup, and emits exact toast `kimo removed a clip you were editing · undo` with a deliberate compensating action. That action is not silently inserted into automatic user undo history. Incoming text suggestions preserve action/version provenance. A local lock filter is not evidence that the server enforces agent locks.

Outbound batches serialize and use the latest acknowledged base. 409 is evidenced nonacceptance: fetch project AND assets, retain newer authority over stale snapshots, validate IDs/locks/bounds again, retry ONCE. A second 409 or failed refresh preserves the unsaved group and reports failure. Transport errors, server errors and uncertain ACK reconciliation are acceptance-unknown, not proof of rejection; add/split/remove-add groups are not automatically replayed. Unsent offline groups may be flushed after reconnect; known failed or unknown groups block later outbound dispatch until explicitly reconciled. HTTP response versions reconcile own echoes in either ordering. Metadata-free in-flight events are conservatively projected without reapplying a possible own non-idempotent batch; identity is never guessed from matching op contents.

Optional `project.ops.author:user|agent` and `clientMutationId:string`, and optional `/ops` request `clientMutationId`, are correlation PROPOSALS, NOT production agreement or idempotent replay guarantees. KimoClient accepts optional fourth ops options `{signal,clientMutationId}`. Default service requests supply only cancellation signal; identity is sent only with explicit `EditContext.mutationIdentity:true` after producer agreement. Unknown-author events are never fabricated as user or agent history. Action history uses actual actionId; snapshot actionIds alone cannot supply reload preimages.

### Local durability, history and command policies

Injected storage holds format-1 outbox keyed by session AND project, with base revision, parsed ops, IDs and statuses. Only unsent groups auto-flush. A sending group is persisted as unknown before network dispatch so reload cannot blindly replay a possible accepted request. Storage denial/quota gives `unsaved`, not a local-save claim. Malformed storage is retained and exposed as unsaved rather than silently overwritten. This is session-scoped device recovery, not server persistence. Session disposal aborts signal-aware writes, drops draft/timers owned here (there are no session timers), removes subscriptions and invalidates stale callbacks; it cannot revoke a request already accepted by a server.

User undo/redo records conditional minimal field before/after changes, not whole-project snapshots. Same-field later edits cause an explicit conflict; unrelated later agent fields survive. Inverses merge nested transform/text/effect changes into current state. Optional top-level absence has no unset patch, so restoration can use a current-state remove/add of that clip while preserving unrelated current fields; uncertain delivery of that batch is never retried. A new user group clears user redo; incoming AI does not. Agent revert is a NEW user compensation against locally observed actual-action preimages; history with missing preimages/inverse expressibility is unavailable, never invented after reload. Marker.remove is not proposed. Empty-track removal exists only for reversible created tracks.

Pure shared validation is used for gesture/numeric/keyboard commits: finite values, minimum one frame, source bounds when metadata is available, non-dangling tracks/assets/masks, same-kind unlocked movement, clip/track locks, visible crop extent, text/audio field applicability and valid split interiors. Preview and commit parse actual shared schemas, not casts. No source duration is fabricated when metadata is absent. Speed preserves source span with fixed start/in, no implicit ripple, and clamps at one frame. Main V1 is the named V1 video track, else the first video track. Header display ordering sorts a copy, never compositor tracks in-place. Ripple deletion closes union intervals once. Duplicate placement defaults after the selected span with fresh clip/effect/link-group IDs and remapped effect keyframe paths. Detach preserves source timing/audio gain/volume keys/fades/clock while silencing the original and linking the new audio; volume automation is removed from the original so a volume key cannot override mute. Global audio off patches audio-bearing track mute, not transport volume. These are engineering defaults, not inferred user preferences.

Nested command rebasing additionally retains sparse touched-clip intent baselines and original parsed ops in the format-1 outbox. `rebaseCommands` preserves the wire operation names, including `clip.split` and one `text.update`, while merging only changed nested leaves over fresh authority. Thus an X-position edit does not carry a stale rotation value over a queued agent rotation, including after 409 and offline reload. Same-count text-word changes can preserve independent newer word timing; changed-count word structures replace their segment structure rather than leaving dangling extra tokens. Sparse baselines are for pending intent, not snapshot-based undo. Client session reads optionally accept a cancellation signal as well as writes. Late preview/cancel cleanup is harmless after disposal; a late commit resolves cancelled. Incompatible same-field or overlapping-history inverses remain explicit conflicts/unavailable rather than fabricated reverts.

## Phase 8 optional event proposals, 2026-10-27

These additions are implemented in the shared validator and synthetic producer only, not proven production support. Legacy packets remain valid:

- `asset.added.actionId?: string` correlates a web resource with an actual action, never the latest tool by timing.
- `agent.action.end.resultSummary?: string` carries a producer summary; absence remains unknown.
- `agent.message.stream?: {sequence: nonnegative safe integer, done: boolean}` uses message ID and cumulative text. Duplicate/out-of-order or non-cumulative updates do not create invented words.
- `interrupt.clientMessageId?: string` and `agent.status.inReplyTo?: string` are optional identity proposals. The default frontend still sends legacy interrupts and permits one pending note until identity capability is explicitly agreed.

The synthetic held-step runner processes interrupts at safe completion boundaries, supersedes stale queued work and acknowledges its bounded test step within 400ms. Hard pause cancels an uncommitted step and freezes timers until resume. This is not proof of production cancellation, general 400ms latency or engine locking. SAM metadata describes the original synthetic ellipse, not inferred person segmentation.
