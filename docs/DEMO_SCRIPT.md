# Three-minute demo script

**Exactly 180 seconds, authored, not recorded or rehearsed.** Timing is an edit
plan, not a performance measurement. Keep an on-screen label throughout:
`synthetic mock preview` unless a separately verified real backend recording is
actually being shown. No production, engine, model, GPU or audio-fidelity claim
may be inferred from UI events or synthetic media.

## Before recording

Use synthetic mixed files (video, image, audio and a short PDF) with redistribution
rights; no real private uploads. Prepare the original patterns from the existing
fixture generator. Obtain an authorized disposable runner; do not reuse the active
shared browser. Confirm actual transport, GPU initialization, playback, microphone/
audio output, render, download and test session lifetime before choosing a branch.
Do not hide an unavailable renderer with an inserted stock frame or fake canvas.

For a real branch, the backend owner must confirm model execution, SAM mask
provenance/target correlation, web image source/license, speech timings, music
mix and actual composition output. Test both the visual mask and audible output.
Record the real capability receipt and source ref with the footage. If unavailable,
use the honest mock wording below and label the missing capability; do not narrate
SAM, web search or audio generation as something that happened.

## Recording stop conditions and truthful editing

If upload/navigation/render/download is blocked, do not manufacture continuity.
Use the assigned interval to show the actual error and explain the boundary, or
record later on an authorized capable runner. A pre-existing direct Studio session
must be labelled restored, not presented as the preceding prompt's result. Keep
session/job identities consistent without exposing signed media URLs or tokens.

The currently observed managed runner fails before renderer initialization; Play
is disabled. The mock's final video is silent and composition-independent. A
successful download is therefore only transport/UI evidence. Native sharing,
production retention, auth, quotas, model attribution, GPU FPS, AT acceptance and
launch are outside this demonstration. Do not remove these disclosures merely to
fit a competition claim. The 180-second plan can use honest fallback narration
without pretending the missing SAM/web-image/audio capabilities ran.
