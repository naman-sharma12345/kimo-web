For alpha a, composite each sRGB channel as `a * foreground + (1-a) * background`,
then linearize sRGB (channel <= 0.04045: channel/12.92; otherwise
`((channel+0.055)/1.055)^2.4`). Relative luminance is
`0.2126R + 0.7152G + 0.0722B`; contrast is `(Llighter+0.05)/(Ldarker+0.05)`.
The quoted rounded ratios use cream `#F5F1E7` over ink-1 `#0E0E0F`. Rendered axe
must still inspect actual surfaces, backgrounds, focus indicators and text sizes.
