# Fixture provenance

These fixtures are original deterministic synthetic test patterns, a sine tone, a binary ellipse luma mask and an identity 64-cube LUT atlas. scripts/fixtures.mjs uses FFmpeg for media and scripts/fixture-png.mjs for PNGs. The mask is not a SAM inference result; the LUT uses top-left origin, red x, green y and blue tile index in an 8x8 grid. No stock media, recordings, or third-party music. Dedicated CC0-1.0 by the project for these generated fixtures only. They are not represented as real footage. Phase 9 adds silent 8-second portrait (1080x1920) and square (1080x1080) MP4 test patterns and real JPEG landscape/portrait/square posters. These illustrative bytes are not project compositions, caption burn-in, engine output, model execution or mixed audio. JPEGs are repeated for available synthetic progress frames; they do not depict editorial progress.

The spec suggested Pexels/Pixabay CC0 URLs, but those providers’ standard licenses are not CC0. No unverified downloads were made.
