# Fixture provenance

These seven fixtures are original deterministic synthetic test patterns, a sine tone, a binary ellipse luma mask and an identity 64-cube LUT atlas. scripts/fixtures.mjs uses FFmpeg for media and scripts/fixture-png.mjs for PNGs. The mask is not a SAM inference result; the LUT uses top-left origin, red x, green y and blue tile index in an 8x8 grid. No stock media, recordings, or third-party music. Dedicated CC0-1.0 by the project for these generated fixtures only. They are not represented as real footage.

The spec suggested Pexels/Pixabay CC0 URLs, but those providers’ standard licenses are not CC0. No unverified downloads were made.
